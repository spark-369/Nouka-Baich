# Nouka Baich

A rhythm-based boat racing game built with Next.js and React.

## Description

Nouka Baich is an exciting rhythm game where you control a boat by tapping in time with drum beats. Race against an AI opponent across a scenic river, building combos and managing stamina to reach the finish line first!

## Features

- **Rhythm Gameplay**: Tap or press space in sync with the drum beats
- **Difficulty Levels**: Easy, Normal, and Hard modes with varying beat speeds and AI difficulty
- **Scoring System**: Earn points with combo multipliers for perfect timing
- **Stamina Management**: Keep your stamina up by hitting beats; run out and the race ends
- **Leaderboard**: Track your high scores locally
- **Pause Functionality**: Pause and resume the game anytime
- **Responsive Design**: Play on desktop or mobile devices

## How to Play

1. Select your difficulty level from the menu
2. Start the race
3. Listen to the drum beat and tap/press space key (or touch on mobile) in perfect timing
4. Hit beats to increase speed, stamina, and combo
5. Miss beats to lose speed and stamina
6. Race to the finish line before time runs out (60 seconds) or stamina depletes
7. Beat the AI opponent to win!

## Installation

1. Clone the repository
2. Navigate to the project directory: `cd my-app`
3. Install dependencies: `npm install`
4. Run the development server: `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000) in your browser

## Technologies Used

- Next.js 16
- React 19
- Tailwind CSS
- HTML5 Audio API

## Controls

- **Space Key**: Hit the beat (Desktop)
- **Touch**: Tap to hit the beat (Mobile)
- **Pause**: Click the pause button during gameplay
